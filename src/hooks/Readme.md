# Hooks

This folder contains React Hooks created for use in this plugin's Block Editor code.

Organize each hook in a subfolder and add a readme file explaining what the hook is and how to use it.

| Hook | Purpose |
|------|---------|
| [usePost](./usePost/Readme.md) | The post open in the Block Editor: its ID, post type and post type object. |
| [usePostMeta](./usePostMeta/Readme.md) | Get and set one post meta value of a post. |
| [usePageTree](./usePageTree/Readme.md) | Load the page tree one level at a time from the `bu-navigation/v1/tree` REST route. |
